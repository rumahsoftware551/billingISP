# Jaringanku v1.1.0 Stable Acceptance

A production release is accepted only when:

1. `jaringanku:phase15-preflight` passes.
2. `jaringanku:phase15-security-audit --strict` passes in production.
3. Database migration status is clean.
4. PostgreSQL schema backup succeeds.
5. Health readiness responds through the production reverse proxy.
6. RADIUS is allowlisted to real NAS addresses only.
7. Phase 04–15 regression has passed in the target release environment or an equivalent staging environment.
8. Release checksum verification succeeds before deployment.

Do not use `docker compose down -v` during upgrades because it deletes named volumes.
